# dirfi-fpt — Système expert d'aide à la décision pour une Direction des Finances

Skill Claude/Codex destiné à un **Directeur des Finances** en collectivité
territoriale française. Il cadre le besoin financier, oriente vers la bonne base
légale et le bon écrit, et sécurise les frontières de compétence
(ordonnateur / comptable public, assemblée / exécutif, finances / RH).

> Dépôt en cours d'initialisation. Le contenu du skill est développé sur la
> branche `claude/skill-direction-finances-qrtfx8`.
